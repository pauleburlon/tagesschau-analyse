Methodik

  • Quelle: öffentlich ausgestrahlte tagesschau 20:00 Uhr (ARD / Das Erste), Sendungsarchiv von tagesschau.de.
  • Transkription: automatisch mit OpenAI Whisper, Modell large-v3-turbo (int8).
  • Auswertung: Python (pandas, matplotlib); alle Werte werden bei jedem Build aus den Rohdaten neu berechnet.
  • Stand: 30.03.2014 – 01.12.2025, 3.895 Sendungen, davon 100,0% transkribiert.
